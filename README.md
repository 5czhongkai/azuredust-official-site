# AzureDust 官网

蓝尘数字智能科技有限公司官网静态页面，面向移动端优先展示和微信传播场景。

## 项目结构

```text
index.html
styles/main.css
scripts/main.js
assets/
```

## 本地预览

```bash
python3 scripts/preview.py
```

默认地址：

```text
http://127.0.0.1:4173
```
